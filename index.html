Unconfirmed assumptions in this build — each was built with a stated default, not yet confirmed with Xukun:

    1 — Reference Panel

    Paste the protein/peptide panel once (tab-delimited: Measure Type, Biofluid/Location, Measure Identifier, Units, Protein, MYCO ID, PEPTIDE ID, Peptide, LLOQ, ULOQ — one row per line). Every later sample-column paste is values-only, aligned by row position to this table.

    2 — Add Sample Columns

    Set up the reference panel first (Reference Panel tab) — sample values are aligned by row position to it.

    Batches

    Batches are created once and picked from a list afterward — no free-text batch field on every column.

    Step A — paste the raw grid

    Paste a full tab-delimited block copied straight from the sheet — one line per peptide (same order as the reference panel), as many sample columns as you like in one go. If you copy straight from the sheet including its own header rows, the barcode row (and a label row above the data, if present) is auto-detected and used to fill in each column's Sample ID.

    Step B — classify each column

    Every column needs a Sample ID, a category, and a batch. Rerun/Duplicate columns must link to the First-run column they belong to (from this paste or already saved).
